### User Stories

1. As a new user, I want to register with my email and password, so that I can create an account and access the app.

2. As a user, I want to be able to slide habits to delete them or to mark it as done, so that it becomes
more time efficient for me.

3. As a user, I want to view information about a selected item, so that I can make informed decisions.

4. As a user, I want confirmation when data is successfully saved or fails, so that I trust the system with my information.

5. As a user, I want cached responses for frequently requested data, so that the app feels fast. 

6. As a user, I want a visible sign-out option, so that I can end my session securely.

7. As a user, I want to update my profile details, so that my account stays current.

8. As a user, I want to receive push notifications for important events, so that I stay informed.

9. As a returning user, I want to log in with my credentials, so that I can continue using my account with my already saved information and data without having to create a new one.
